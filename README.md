# MEDUCA Planifica

Plataforma educativa para crear planeamientos curriculares de MEDUCA Panamá.

## Publicación con GitHub Pages

1. Suba todos los archivos de esta carpeta a la rama `main` del repositorio.
2. Abra **Settings > Pages**.
3. En **Build and deployment**, seleccione **Deploy from a branch**.
4. Seleccione la rama **main** y la carpeta **/(root)**.
5. Presione **Save**.

La dirección esperada es:

https://santo217.github.io/meduca-planifica/

Después de publicar, agregue esa dirección en Supabase, dentro de Authentication > URL Configuration, como Site URL y Redirect URL.
